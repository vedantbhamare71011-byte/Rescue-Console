    PRESENTATION GUIDE

    A real interface. An honest demo.

    Demo sandbox: Take off, click the viewport, then use WASD, R/F and Q/E. Run demo mission for an automatic virtual circuit. Click annotations to focus them. Orbit, Follow and Top change only your camera.

    Realtime: Displays externally supplied position and attitude on an empty coordinate grid. It never falls back to demo data. Data older than 3 seconds is marked stale. Flight controls are disabled.

    Camera views: Demo views are rendered graphics, not real video or thermal measurements. Realtime accepts JPEG frames via the documented local API.

    Offline: Everything is bundled locally. Copy this folder to a laptop with Python 3.9+ and a WebGL-capable browser. Run python server.py, then open http://127.0.0.1:8787.

    See README.md for authenticated telemetry, coordinate conventions and the optional SSH tunnel. The producer token appears only in the server terminal.
